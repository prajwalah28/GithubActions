GitHub Actions Workflow Runner Simulator

Trigger a simulated GitHub Actions automation workflow. Watch the runner spin up, fetch your branch, lint/verify files, and output standard logs! 

name: Lint and Validate Files

on:
  pull_request:
    branches: [ main ]

jobs:
  validate-code:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Validate HTML Structure
        run: npx htmlhint index.html

      - name: Check CSS Formatting
        run: npx stylelint style.css
name: Deploy Static Webpage to Pages

on:
  push:
    branches: [ main ]

jobs:
  deploy-pages:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repo
        uses: actions/checkout@v4

      - name: Deploy to GitHub Pages Site
        uses: actions/configure-pages@v4

Learning Milestones

Track your progress through your Git branching & CI/CD workflow session. Check each step off as you complete it.

  • 1. Initialize Repository

    Create project directory, run git init and link it to a remote GitHub repository.

  • 2. Create your Feature Branch

    Create a dedicated branch using git checkout -b feature-dev.

  • 3. Stage & Commit Changes

    Develop HTML & CSS, then run git add . and git commit -m "feat...".

  • 4. Push Branch to Origin

    Upload your branch via git push -u origin feature-dev.

  • 5. Create a Pull Request (PR)

    Open GitHub. Create a Pull Request proposing to merge feature-dev into main.

  • 6. Trigger Actions & Merge

    Wait for automated GitHub workflows to pass, then merge your PR on GitHub! 🚀
